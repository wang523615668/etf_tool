# ETF 拯救世界投资仪表盘

本地网页工具，访问：`http://127.0.0.1:8888`

## 当前第一版功能

- 长赢 150 份 / S 定投持仓同步样例
- 仓位旭日图：方向 → 产品 → 份数
- 本地买卖提醒样例
- E大操作 vs 本地提醒对比复盘

## 启动

```bash
cd /vol1/1000/openzl/etf_tool
./run.sh
```
